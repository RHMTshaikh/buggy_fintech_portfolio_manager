# Fintech Portfolio Manager

Institutional-grade portfolio management, double-entry ledger, algorithmic risk evaluation, and AI robo-advisory platform.

## Architecture Highlights
- **Domain-Driven Design (DDD)**: Strict separation of concerns (Core, Market Data, Portfolio, Trading, Risk, AI).
- **Double-Entry Ledger**: Immutable transaction logging for cash and equity balances.
- **Asynchronous Execution**: Decoupled order validation, risk checks, and queue-based execution.
